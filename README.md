Java Maven CI/CD Project

Project Overview

This project demonstrates a Java application built using Apache Maven and includes a Jenkinsfile for Continuous Integration and Continuous Deployment (CI/CD).

The project helps understand Java project management, build automation, and CI/CD concepts.

Objectives

- Develop a Java application.
- Manage project dependencies using Maven.
- Build the application using Maven.
- Understand CI/CD using Jenkins.
- Automate the build process through a Jenkins pipeline.

Technologies Used

- Java
- Apache Maven
- Jenkins
- Git
- GitHub

Project Structure

java-maven-cicd/
├── src/
├── .gitignore
├── Jenkinsfile
├── pom.xml
└── README.md

How to Run the Project

1. Install Java JDK.
2. Install Apache Maven.
3. Clone this repository.
4. Open the project directory.
5. Execute the following command:

mvn clean package

CI/CD

This project includes a Jenkinsfile to demonstrate pipeline-based build automation.
